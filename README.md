# Snakes-Ladders-3D
Multiplayer and Online Game up to 4 players
# 🎲 Snakes & Ladders 3D (لعبة السلم والثعبان ثلاثية الأبعاد)

لعبة تفاعلية احترافية للوحة "السلم والثعبان" مبنية باستخدام تقنيات الويب الحديثة **Three.js** للرسومات ثلاثية الأبعاد، و **Node.js مع Socket.io** لدعم اللعب الجماعي أونلاين لحظياً، مع تصميم متجاوب وعمودي متوافق تماماً مع الهواتف الذكية وأجهزة سطح المكتب.

---

## 🚀 المميزات الرئيسية
* **رسومات ثلاثية الأبعاد (3D):** لوحة لعب مرقمة بدقة مع سلالم خشبية وتماثيل ثعابين مصممة بالكامل عبر Three.js.
* **نرد ثلاثي الأبعاد حقيقي:** نرد 3D يتدحرج بفيزياء دوران واقعية عند كل رمية.
* **لعب جماعي أونلاين (Multiplayer):** نظام غرف خاص (Rooms) يتيح للاعبين التنافس عبر الإنترنت مع إدارة آمنة للأدوار على الخادم (Anti-Cheat).
* **اللعب ضد الكمبيوتر (AI):** إمكانية اللعب بشكل محلي ضد خوارزميات الكمبيوتر في حال عدم توفر خصم.
* **تصميم متجاوب:** واجهة مستخدم أنيقة مبنية بواسطة **Bootstrap 5** تدعم اللغة العربية والتخطيط العمودي المناسب للشاشات المختلفة.

---

## 🛠️ التقنيات المستخدمة
* **Frontend:** HTML5, JavaScript (ES6+), Three.js, Bootstrap 5.
* **Backend:** Node.js, Express, Socket.io.
